# Lele ICT Pro

## Overview
Lele ICT Pro is a professional TradingView indicator built using Pine Script v6.

The project focuses on Institutional Order Flow, ICT (Inner Circle Trader) concepts, and Smart Money Concepts (SMC), with the goal of delivering high-probability trading setups while minimizing false signals.

## Vision

Accuracy over quantity.

Rather than producing many signals, Lele ICT Pro only generates trade opportunities when multiple institutional confirmations align.

## Core Features

- Market Structure (BOS & CHOCH)
- Swing Highs & Swing Lows
- Liquidity Detection
- Equal Highs & Equal Lows
- Liquidity Sweeps
- Fair Value Gaps (FVG)
- Order Blocks
- Breaker Blocks
- Premium & Discount Zones
- Multi-Timeframe Bias
- Session Filters
- Confidence Score
- Dashboard
- TradingView Alerts
